#  Landing Page – Banda de Rock (Eventos y Promoción)

# Description 

A responsive homepage designed for a rock band, including event dates, band pictures, and more band information.

## Technologies Used

- HTML5 (Semantic tags)
- CSS3 (Flexbox & Grid Layout)
- Responsive Design (Media Queries) 

# Project structure

The project is organized in a modular way to facilitate maintenance:

```

📂 assets/  
 - 📂 icons/  
 - 📂 img/             
 - 📂 css/   
  - 📄 about.css 
  - 📄 events.css
  - 📄 footer.css
  - 📄 header.css
  - 📄 hero.css   
  - 📄 multimedia.css           
  - 📄 style.css        
 - 📂 js/       
  - 📄 main.js          
📄 index.html           
📄 README.md          

```

# How to run or view the project locally

1. Clone or download this repository. <https://github.com/Lneiras/Prueba-Desempe-o-HTML-CSS.git>
